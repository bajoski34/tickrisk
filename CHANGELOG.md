# Changelog

## 0.1.0 (2026-10-14)

First release.

- Instruments: equity, European option, fixed-rate bond, FX forward
- Black-Scholes-Merton pricing, Greeks and implied volatility
- Book sensitivities, stress testing with a starter scenario library, historical and delta-normal VaR with expected shortfall, P&L explain
- Streaming `RiskEngine` with limits and subscribers
- Hash-chained, idempotent, replayable run log
- `tickrisk` CLI: demo, stream, verify, replay
